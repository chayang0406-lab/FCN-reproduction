# 分岔点定位：E0 与作者轨迹在 ep14→ep15 之间分岔（2026-11-19 01:20）

> 这是本项目最重要的一个科学发现。它不是「复现失败」，
> 而是**精确地定位了「复现在哪一点开始失效，以及为什么」**。

### 量级对比（这就是「分岔点」的定义）
```
ep1-14 : max|Δ| = 7.60e-5,  mean|Δ| = 2.93e-5,  14/14 全部 ≤ 1e-4
ep15   : |Δ| = 2.62e-3                             ← 超出 2 个数量级
```

**这不是渐变，是突变。** ep14 还是 7.5e-5（浮点量级），ep15 就跳到 2.6e-3。

## 二、机制层证据：分岔的原因不是「模型不同」

�ל日志计数器（截至 ep15）：
```
Epoch=N end           : 15
Save best model       : 15     ← 每一轮都刷新 best
Reduce learning rate  :  0     ← 从未触发
Monitor STOP          :  0
early stop            :  0
```

**`Save best` 与 `Epoch end` 完全相等（15 = 15），说明 `_stopping_steps` 每一轮都被重置为 0，
降 lr 的前置条件从未满足。**

而作者在 ep14 的组内差是 **−4.0×10⁻⁵**（下降）→ 触发降 lr → ep15 跳升 **+0.0028**。
我们的 ep14 组内差是 **+5.3×10⁻⁵**（上升）→ 刷新 best → 不降 lr → ep15 只涨 +0.0001。

### 分岔的精确机制
```python
if monitor_value < best + 1e-6:      # min_delta = 1e-6
    _stopping_steps += 1
    if reduce_lr_on_plateau: lr *= 0.1
```
| | ep13 → ep14 组内差 | 判定 | 结果 |
|---|---|---|---|
| 作者 | −4.0×10⁻⁵ | 未改善 | 降 lr 1e-3→1e-4 → ep15 跳升 +0.0028 |
| 我们 | **+5.3×10⁻⁵** | 改善 | 刷新 best，lr 不变 → ep15 只涨 +0.0001 |

**两者相差 9.3×10⁻⁵，与我们实测的跨平台浮点差异（≤7.6×10⁻⁵）同量级。**

## 三、这个发现的科学价值（远超「复现成功/失败」的二元判断）

### 1. 它把「复现」从二元判断变成可定位的过程
传统表述：「我们复现了 / 没复现」。
本项目的表述：**在 ep14 之前，14 个独立评估点的差异全部 ≤7.6×10⁻⁵；
分岔发生在 ep14 那一次 `min_delta=1e-6` 的判定上；分岔后路径不同。**

### 2. 它证明了「对齐」与「复现最终值」是两件不同的事
- **对齐**：ep1-14 逐轮差异在浮点量级 → 数据/结构/超参/优化器全部正确
- **最终值相同**：需要「分岔点上的抛硬币结果相同」→ 不由实现质量决定

**换句话说：前 14 轮对齐证明了我们的实现是对的；
ep15 之后的差异不构成「实现不对」的证据。**

### 3. 它给出了一个可推广的结论
> 对于带 `ReduceLROnPlateau` 的训练任务，**跨平台复现的边界不在「模型实现」，
> 而在「首次触发 lr 衰减的那一次判定的稳定性」**。
> 因为该判据 `cur < best + min_delta` 中的 `min_delta`（1e-6）小于跨平台浮点差异（1e-5 量级），
> 判定结果本质上由噪声决定。

## 四、必须写清的措辞边界

### ✅ 可以说
- 「ep1–ep14 逐轮对齐，差异在浮点末位量级」
- 「分岔发生在 ep14 的 lr 衰减判定点」
- 「我们的 lr 衰减**推迟**（而非『没有衰减』）」
- 「最终 AUC 的差异源于调度时机，不构成模型实现错误的证据」

### ❌ 不能说
- 「我们复现了最终 AUC」（还没跑到，且很可能不同）
- 「我们的 lr 没有衰减」（机制没失效，是前置条件未满足）
- 「论文/作者的做法有问题」（作者的做法没问题，只是对噪声敏感）
- 「15/15 轮全部对齐」（ep15 已差 2.6e-3，统计必须分段）

## 五、后续待观测

1. **第一次 `Reduce learning rate` 出现在哪一轮**（决定是 B1 还是 B2）

3. **降 lr 之后一轮是否跳升**

4. 最终 `lr_decay_epochs` / `epochs_trained` / valid AUC / test AUC

只能靠 `lr_decay_epochs` 是否为空区分——不能靠 AUC。**
